## Česky

Jednoduchá mini hra ve stylu **Space Invaders** vytvořená v **MakeCode Arcade**.

Hráč ovládá malou raketku dole na obrazovce, střílí nahoru a snaží se zasáhnout mimozemšťany, kteří se objevují nahoře a pomalu letí dolů.

Projekt je určený hlavně pro začátečníky. Celá hra je velmi krátká — v JavaScriptu má přibližně 60 řádků včetně definic obrázků.

## Jak se hra ovládá

* **Doleva / doprava** — pohyb raketky
* **Tlačítko A** — výstřel

## Cíl hry

Sestřel co nejvíce mimozemšťanů.

Za každého zasaženého mimozemšťana získáš bod. Když se mimozemšťan dostane dolů nebo narazí do hráče, hráč ztratí život.

## Co se v projektu procvičuje

Na tomto jednoduchém příkladu si děti nebo začátečníci mohou vyzkoušet:

* vytvoření hráče jako sprite,
* ovládání sprite pomocí ovladače,
* vytvoření střely,
* náhodné vytváření nepřátel,
* pohyb nepřátel směrem dolů,
* detekci kolize mezi střelou a nepřítelem,
* počítání skóre,
* ubírání životů,
* jednoduché efekty při zničení sprite.

## Proč je hra tak jednoduchá?

Cílem není vytvořit dokonalou kopii původních Space Invaders, ale malý a srozumitelný projekt, který jde snadno přečíst, upravit a vysvětlit.

Hra je vhodná jako první krok před složitějšími verzemi, například s více druhy nepřátel, rychlejší obtížností nebo lepší grafikou.

## Možné nápady na vylepšení

* přidat pozadí s hvězdami,
* postupně zrychlovat mimozemšťany,
* přidat více druhů nepřátel,
* přidat zvuky,
* přidat konec hry při určitém skóre,
* přidat štíty nebo bonusy,
* upravit obrázky hráče, střely a mimozemšťana.

## English

A tiny **Space Invaders** style mini game made in **MakeCode Arcade**.

The player controls a small spaceship at the bottom of the screen, shoots upward, and tries to hit aliens that appear at the top and slowly move down.

This project is designed mainly for beginners. The whole game is intentionally very small — the JavaScript version has about 60 lines, including the image definitions.

## Controls

* **Left / right** — move the spaceship
* **A button** — shoot

## Goal

Shoot as many aliens as possible.

Each destroyed alien gives you one point. When an alien reaches the bottom of the screen or hits the player, the player loses one life.

## What you can learn from this project

This small example introduces several basic MakeCode Arcade ideas:

* creating a player sprite,
* moving a sprite with the controller,
* creating a projectile,
* spawning enemies at random positions,
* moving enemies downward,
* detecting overlap between a projectile and an enemy,
* changing the score,
* changing lives,
* using simple destroy effects.

## Why is the game so simple?

The goal is not to create a full clone of the original Space Invaders, but a small and readable project that is easy to understand, explain, and modify.

It can be used as a first step before building more advanced versions with more enemies, increasing difficulty, sounds, or improved graphics.

## Ideas for improvements

* add a starry background,
* make aliens faster over time,
* add different enemy types,
* add sound effects,
* add a win condition,
* add shields or bonuses,
* change the player, projectile, and alien images.
